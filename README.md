# 🎤 Voice-Controlled Budget Tracker 💰

A Python-based budget tracker that helps you manage expenses, set a budget, and track spending by category.  
Now enhanced with **voice control**, so you can add expenses hands-free!


## 🚀 Features
- Set a daily budget
- Add expenses by typing or using your **voice**
- Get category-wise totals
- Detect if you exceed your budget
- Save all expenses to `expenses.csv`


## 🛠️ Requirements
- Python 3.x

pip install -r requirements.txt
